# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want a welcoming, harassment-free community for everyone. Be respectful, assume good
faith, and accept constructive feedback. Harassment, personal attacks and other
unacceptable behavior are not tolerated.

Report concerns privately to the maintainer via a
[GitHub security advisory](https://github.com/owenmonagan/freedictate/security/advisories/new)
or by contacting [@owenmonagan](https://github.com/owenmonagan). Reports are handled
confidentially, and enforcement follows the Covenant's guidelines.
