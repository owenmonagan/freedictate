Mac dictation not working? Here's how to fix it

Most dictation problems on a Mac come down to three things: the microphone, a permission, or the thing doing the transcribing. Work through them in order.

This guide covers both Apple's built-in Dictation and FreeDictate. Start with the general checks, since they apply to every dictation app, then jump to the section for the tool you use.

First: check the microphone

  1. Open System Settings → Sound → Input. Pick the microphone you expect to use and speak. The input level should move.
  2. If you use AirPods or a USB headset, make sure it's actually selected as the input. Macs often switch inputs when a device connects.
  3. Raise the input volume if the level barely moves.

If the level doesn't move here, no dictation app will work. Fix the hardware or input selection first.

Apple Dictation not working

  • Make sure it's on. Go to System Settings → Keyboard and turn on Dictation. Note the shortcut it shows.
  • Check the shortcut. If another app uses the same shortcut, pick a different one in the Dictation settings.
  • Check the language. Dictation uses the language set in Keyboard settings. Speaking a different language gives poor results.
  • Check the field. Click into a text field first. Dictation can't type into something that doesn't accept text.
  • Restart. Turning Dictation off and on, or restarting the Mac, clears many stuck states.

If Apple Dictation keeps letting you down, or you want a different way to start it, FreeDictate is a free alternative that you start with one button of your choosing.

FreeDictate not working

FreeDictate runs inside Hammerspoon and uses a local speech engine. Its messages tell you which part needs attention.

Nothing happens when I press my button

  1. Check that Hammerspoon is running and the FreeDictate icon is in the menu bar. If not, open Hammerspoon.
  2. Choose Set talk key… from the menu and press your button again. It can be any key, combo, modifier, or the middle, back or forward mouse button.
  3. If you use a mouse with its own software, make sure that software isn't remapping the button you chose.
  4. Still nothing? Choose Reset to ⌥Space and try ⌥ Space.

"Microphone access needed"

Hammerspoon doesn't have microphone permission. Open System Settings → Privacy & Security → Microphone and turn on Hammerspoon. The Setup window has a button that opens this pane. You can reopen Setup from the menu with Setup….

"Copied instead — press ⌘V to paste"

Hammerspoon doesn't have Accessibility access, so FreeDictate can't paste for you. Your words are on the clipboard, so press ⌘V now. Then turn on Hammerspoon in System Settings → Privacy & Security → Accessibility. If it's already on but pasting still fails, turn it off and on again.

"Can't reach speech engine"

The local whisper-server isn't answering on 127.0.0.1:8178. FreeDictate falls back to whisper-cli when the server is down, but that's slower. To fix it:

  1. Re-run ./install.sh from the FreeDictate folder, or ~/.freedictate if you used the one-liner. It's safe to re-run and restarts the agent if needed.
  2. Check the agent and its log: 
    launchctl print gui/$(id -u)/dev.freedictate.whisper-server
tail ~/Library/Logs/freedictate-whisper-server.log
  3. If the installer says whisper-server wasn't found, run brew reinstall whisper-cpp.
  4. If the log complains about the model, make sure ~/.local/share/whisper/ggml-large-v3-turbo-q5_0.bin exists. Re-running the installer downloads it again if it's missing.

The level meter doesn't move

The pill at the bottom of the screen shows a live level while you talk. If it stays flat, FreeDictate is recording the wrong input or none at all. Go back to the microphone checks above.

Words are pasted in the wrong place

Text goes to whichever app has focus when the paste happens. Click into the field before you start, and stay there until the words appear.

It started recording by accident

Press Esc to cancel. Nothing is pasted. A press shorter than 0.35 seconds counts as a tap and starts hands-free recording, so a quick accidental press can start it. Tap again or press Esc to stop.

Fresh start

Reload Hammerspoon from its menu bar icon with Reload Config, or re-run ./install.sh. If you want to start completely clean, run ./uninstall.sh, then install again. The speech model is kept unless you use --purge, so reinstalling is quick.
