Guide

Run Whisper locally on your Mac

whisper.cpp brings OpenAI's Whisper speech models to the Mac with no Python and no cloud. Here's the setup FreeDictate uses, step by step.

Whisper is an open speech recognition model from OpenAI. whisper.cpp is an open-source C/C++ port that runs it efficiently on ordinary computers, including Apple silicon Macs. It's what powers FreeDictate. This guide shows how to run it yourself, and how FreeDictate wires it up into one-button dictation.

If you just want dictation, the FreeDictate installer does every step below for you.

1. Install whisper.cpp

The easiest way is Homebrew:

brew install whisper-cpp

This gives you two tools you'll use: whisper-cli, which transcribes a file and exits, and whisper-server, which keeps a model loaded and answers HTTP requests.

2. Download a model

whisper.cpp uses models in its own ggml format. FreeDictate uses ggml-large-v3-turbo-q5_0.bin:

mkdir -p ~/.local/share/whisper
curl -fL -o ~/.local/share/whisper/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin

It's about 550 MB. Why this one?

  • large-v3-turbo is a faster version of Whisper's large-v3 model with fewer decoder layers. It keeps most of large-v3's accuracy at a much lower cost, which is what you want for dictation.
  • q5_0 means the weights are quantized to about 5 bits. The file is much smaller and loads faster, with only a small quality trade-off.

Smaller models such as base or small are quicker but make more mistakes. For dictation, where you read the result right away, large-v3-turbo is a good balance.

3. Try it on a file

Whisper expects 16 kHz mono audio. Record a few seconds with ffmpeg, then transcribe:

brew install ffmpeg
ffmpeg -f avfoundation -i ":0" -ar 16000 -ac 1 -t 5 test.wav
whisper-cli -m ~/.local/share/whisper/ggml-large-v3-turbo-q5_0.bin -f test.wav

macOS will ask for microphone permission for your terminal the first time. If :0 isn't your mic, list devices with ffmpeg -f avfoundation -list_devices true -i "".

4. Keep it loaded with whisper-server

whisper-cli loads the model every time it runs, which adds a delay. For dictation you want the model already in memory. That's what whisper-server is for:

whisper-server -m ~/.local/share/whisper/ggml-large-v3-turbo-q5_0.bin \
  --host 127.0.0.1 --port 8178 -l en

Binding to 127.0.0.1 means only your Mac can reach it. Send it audio with a POST to /inference:

curl -s http://127.0.0.1:8178/inference -F file=@test.wav

5. Run it at login with launchd

To keep the server running, FreeDictate installs a LaunchAgent at ~/Library/LaunchAgents/dev.freedictate.whisper-server.plist. It runs exactly the command above, with RunAtLoad and KeepAlive so it starts at login and restarts if it stops. Logs go to ~/Library/Logs/freedictate-whisper-server.log. Check on it with:

launchctl print gui/$(id -u)/dev.freedictate.whisper-server

6. Turn it into push to talk dictation

A server on its own doesn't type for you. FreeDictate adds the missing pieces with Hammerspoon:

  1. It listens for your talk button: any key, combo, modifier, or the middle, back or forward mouse button.
  2. On press it starts ffmpeg recording 16 kHz mono to a temporary file, with a live level meter.
  3. On release (or a second tap) it posts the audio to 127.0.0.1:8178. If the server is down, it falls back to whisper-cli.
  4. It pastes the text into the focused app with ⌘V, then restores your clipboard.
Do thisWhat happens
Hold your button, talk, let goRecording stops when you release. Your words are pasted.
Tap your button, talk, tap againHands-free. A press shorter than 0.35 seconds counts as a tap.
Press Esc while listeningCancels. Nothing is pasted.

Performance notes

  • Apple silicon is recommended. whisper.cpp is well optimized for it.
  • Intel Macs work, but expect longer waits for transcription.
  • Memory: the server keeps the model loaded, so it uses some RAM while running. That's the trade for instant results.

Skip the manual steps

Everything above is what ./install.sh does. It's idempotent, so running it again repairs or updates the setup, and ./uninstall.sh removes the LaunchAgent and Hammerspoon hooks cleanly.

git clone https://github.com/owenmonagan/freedictate.git
cd freedictate
./install.sh
