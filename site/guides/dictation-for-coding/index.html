Guide

Voice to text for coding on Mac: Claude Code, Cursor and the terminal

Code is mostly symbols, but a lot of a developer's day is prose. Prompts, reviews, commit messages, docs. That part is faster said than typed.

Dictating code itself, symbol by symbol, is slow and awkward. That's not what this guide is about. The win for programmers is everything around the code: explaining a bug to an AI assistant, writing a thoughtful review comment, describing a change in a commit message, or drafting a README. Those are sentences, and most people speak much faster than they type.

FreeDictate is a good fit for this because it's one button and it pastes into whatever has focus: your editor, terminal, browser or chat app. It runs offline, so your code context and internal details stay on your Mac.

Where voice helps most

Prompts for Claude Code, Cursor and the terminal

Some coding tools have their own voice input, but it only works inside that tool. FreeDictate is the same button everywhere: the Claude Code prompt in your terminal, the Cursor chat panel, a shell, or a browser tab. Good prompts are long. They explain what you tried, what you expect, and the constraints. Typing all that feels like a chore, so prompts end up short and vague. Talking makes it easy to give the full picture. Click into the prompt box, tap your button, explain the problem like you would to a colleague, and tap again.

Code review comments

Reviews read better when they explain why. Dictation makes it painless to write "this works, but if the list is empty we'll hit the fallback twice, so consider an early return" instead of "nit: early return".

Commit messages and pull request descriptions

Hold your button in the commit message field and say what changed and why. Then tidy it up.

Docs, tickets and chat

READMEs, design notes, bug reports and Slack replies are all prose. Dictate the first draft and edit by keyboard.

Where to keep typing

  • Code syntax, brackets and operators.
  • Exact identifiers like getUserById, which speech models may split into words.
  • Shell commands where one wrong character matters.

A practical rhythm: speak the sentences, type the symbols. Say "rename the function and update the callers", then type the name in backticks yourself.

Set up for a developer workflow

  1. Install: 
    git clone https://github.com/owenmonagan/freedictate.git
cd freedictate
./install.sh
    You'll need Homebrew. The installer adds whisper-cpp, ffmpeg and Hammerspoon.
  2. Allow Microphone and Accessibility access for Hammerspoon in Setup.
  3. Pick a talk key that doesn't clash with your editor. Editors use a lot of shortcuts, so a lone modifier like Right Option, or a mouse side button, is often the safest choice. The default ⌥ Space is fine if nothing else uses it.
Do thisWhat happens
Hold your button, talk, let goRecording stops when you release. Your words are pasted.
Tap your button, talk, tap againHands-free. A press shorter than 0.35 seconds counts as a tap.
Press Esc while listeningCancels. Nothing is pasted.

How the paste works in editors and terminals

When you finish, FreeDictate pastes with ⌘V into the focused app and then restores your clipboard. In practice:

  • Editors and IDEs receive it like any paste. If your editor auto-formats on paste, that applies too.
  • Terminals receive it as pasted text. Nothing is run until you press Return. Read it before you do.
  • Your clipboard is put back after the paste, so a snippet you copied before dictating is still there.

Privacy for work code

When you talk through a bug you may say internal names, customer details or bits of architecture. FreeDictate never sends audio off your Mac. It records to a temporary file and transcribes with whisper.cpp on 127.0.0.1:8178. There's no account and no cloud. Many teams can use it without a vendor review, but check your own company's policy.

Hackable if you want it

FreeDictate is MIT-licensed and small. The app is a single Hammerspoon Lua file, app/dictate.lua, and the speech engine is a LaunchAgent running whisper-server. If you want to see how it records, transcribes and pastes, it's all readable in one place. The Whisper on Mac guide explains the engine side.

Tips

  • Say punctuation naturally by pausing and phrasing in full sentences. Whisper punctuates from speech.
  • Use tap mode for long prompts so you can gesture, think and look at code while you talk.
  • Press Esc if you lose your train of thought. Nothing is pasted.
