Install

Install FreeDictate on your Mac

One command. Choose your button. Talk. Here is everything the installer does, how to remove it, and how to fix the common snags.

git clone https://github.com/owenmonagan/freedictate.git && cd freedictate && ./install.sh

What you need

  • A Mac. The installer runs on macOS only, on Apple silicon or Intel. Apple silicon is recommended for speed.
  • Homebrew. If it isn't installed, get it from brew.sh and re-run the installer. It also looks in /opt/homebrew and /usr/local if brew isn't on your PATH.
  • git, if you use the one-line installer. If it's missing, run xcode-select --install.
  • About 550 MB of disk for the speech model, downloaded once.

No account and no payment. FreeDictate is MIT-licensed and free.

Install in one command

Clone the repo and run the installer:

git clone https://github.com/owenmonagan/freedictate.git
cd freedictate
./install.sh

Or pipe it straight from GitHub. In that case the installer clones FreeDictate into ~/.freedictate for you, and updates it there if you run it again:

curl -fsSL https://raw.githubusercontent.com/owenmonagan/freedictate/main/install.sh | bash

Safe to re-run.

The installer is idempotent. It skips anything already in place, so running it again is also how you update or repair an install.

What the installer does

  1. Checks your Mac. It stops on anything that isn't macOS, and reports Apple silicon or Intel.
  2. Installs dependencies with Homebrew: whisper-cpp (the on-device speech engine), ffmpeg (records your microphone), and the hammerspoon cask (listens for your button and pastes text). Each is skipped if it's already installed.
  3. Downloads the speech model, ggml-large-v3-turbo-q5_0.bin, from the whisper.cpp model repository to ~/.local/share/whisper/. This happens once.
  4. Starts the speech engine. It writes a LaunchAgent, ~/Library/LaunchAgents/dev.freedictate.whisper-server.plist, that runs whisper-server on 127.0.0.1:8178. Only your Mac can reach it. It starts at login and restarts if it stops. Logs go to ~/Library/Logs/freedictate-whisper-server.log.
  5. Wires up Hammerspoon. It links app/dictate.lua to ~/.hammerspoon/freedictate.lua and adds require("freedictate").start() to ~/.hammerspoon/init.lua. Your other Hammerspoon config is left alone.
  6. Opens Hammerspoon, which loads FreeDictate and shows the Setup window on first run.

Setup: permissions and your button

The FreeDictate Setup window walks you through each step, then lets you try it live.

Microphone

Allow Hammerspoon to use the microphone when macOS asks. FreeDictate records only while you're talking, as 16 kHz mono audio to a temporary file.

Accessibility

Grant Hammerspoon Accessibility access in System Settings, under Privacy & Security. FreeDictate needs it to paste text with ⌘V into the app you're using. It restores your clipboard afterwards.

Start at login

On first run, FreeDictate sets Hammerspoon to open at login, so your button works after every restart.

Your button

Pick any key, a combo, a lone modifier like Right Option, or the middle, back or forward mouse button. The default is ⌥ Space. You can change it any time from the FreeDictate menu bar icon with Set talk key…, or go back with Reset to ⌥Space.

Using it

Do thisWhat happens
Hold your button, talk, let goRecording stops when you release. Your words are pasted.
Tap your button, talk, tap againHands-free. A press shorter than 0.35 seconds counts as a tap.
Press Esc while listeningCancels. Nothing is pasted.

A small pill at the bottom of the screen shows when FreeDictate is listening, with a live level meter, and when it's transcribing.

Uninstall

From the FreeDictate folder (or ~/.freedictate if you used the one-liner), run:

./uninstall.sh

This stops and removes the speech engine LaunchAgent, removes the freedictate.lua link and its line in init.lua, reloads Hammerspoon, and deletes the speech engine log. It leaves require("hs.ipc") and the rest of your Hammerspoon config alone.

The speech model is kept so a reinstall is fast. To remove the model and the ~/.freedictate checkout too:

./uninstall.sh --purge

Hammerspoon, whisper-cpp and ffmpeg stay installed, since other tools may use them. To remove them as well:

brew uninstall whisper-cpp ffmpeg && brew uninstall --cask hammerspoon

Troubleshooting

"Can't reach speech engine"

The whisper-server LaunchAgent isn't answering on port 8178. FreeDictate falls back to whisper-cli when the server is down, but that's slower. Re-run ./install.sh, which restarts the agent if it isn't running. To check it yourself:

launchctl print gui/$(id -u)/dev.freedictate.whisper-server
tail ~/Library/Logs/freedictate-whisper-server.log

If the installer says whisper-server wasn't found, run brew reinstall whisper-cpp.

"Microphone access needed"

Hammerspoon doesn't have microphone permission. Open System Settings, Privacy & Security, Microphone, and turn on Hammerspoon. Setup has a button that opens this pane.

"Copied instead — press ⌘V to paste"

Hammerspoon doesn't have Accessibility access, so FreeDictate can't paste for you. Your words are on the clipboard. Grant Accessibility access to Hammerspoon and it will paste from then on.

Nothing happens when I press my button

Make sure Hammerspoon is running and the FreeDictate icon is in the menu bar. If not, open Hammerspoon. If it is, choose Set talk key… from the menu and press your button again. You can reopen the whole guide with Setup….

I changed something and want a fresh start

Reload Hammerspoon from its menu bar icon with Reload Config, or re-run ./install.sh. Both are safe.
