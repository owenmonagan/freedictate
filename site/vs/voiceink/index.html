FreeDictate vs VoiceInk: a free VoiceInk alternative

VoiceInk and FreeDictate are close cousins: both open source, both on-device Whisper on Mac. The difference is price and how much there is to set up.

The short answer

VoiceInk is one of the closest tools to FreeDictate. Both are open source. Both run Whisper locally on your Mac, so your audio stays on-device. VoiceInk is a native Mac app with more features and settings, and it sells a paid license for the ready-to-run app. FreeDictate is free to install and use, and keeps everything down to one button.

If you're looking for a VoiceInk alternative that costs nothing and has less to configure, FreeDictate is worth a try. If you want more control, VoiceInk is a good choice and we'd say so.

Same foundation, different philosophy

Because both tools use Whisper on-device, raw accuracy for the same model will be similar. What differs is everything around it. VoiceInk offers model choice, optional AI enhancement and app-aware settings. FreeDictate picks large-v3-turbo for you, keeps a local whisper-server running so transcription starts immediately, and pastes exactly what you said.

That's the whole bet behind FreeDictate: most people want dictation to be a button, not a control panel.

Price and licensing

VoiceInk's source is public, and it sells a license for the packaged app. That's a fair way to fund an open-source project. FreeDictate is MIT-licensed and free to install from GitHub with a single command. There is nothing to buy.

How FreeDictate works

FreeDictate is a small open-source app built on Hammerspoon, ffmpeg and whisper.cpp. You pick one talk button: any key, a combo, a lone modifier like Right Option, or the middle, back or forward mouse button. Hold it and talk, then let go. Or tap it to start and tap again to stop. A press shorter than 0.35 seconds counts as a tap. Esc cancels.

While you talk, ffmpeg records 16 kHz mono audio to a temporary file and a small pill at the bottom of the screen shows a live level meter. When you stop, the audio goes to a local whisper-server on 127.0.0.1:8178, which only your Mac can reach. It runs the large-v3-turbo Whisper model, quantized to about 550 MB. If the server is down, FreeDictate falls back to whisper-cli. The text is pasted into whatever app has focus with ⌘V, and your clipboard is put back afterwards.

There is no account, no subscription and no pro tier. It's MIT-licensed, so you can read every line.

Installing

VoiceInk is a native app you download and open. FreeDictate installs with a shell command that uses Homebrew to add whisper-cpp, ffmpeg and Hammerspoon, downloads the model, and sets up a LaunchAgent for the speech engine. If you're comfortable pasting one line into Terminal, it takes a few minutes. If you'd rather never open Terminal, a native app may suit you better.

When to choose VoiceInk instead

  • You want a native app with its own settings window, rather than a Hammerspoon module.
  • You want options: choosing models, AI enhancement or per-app behaviour.
  • You'd rather not use Terminal or Homebrew to install.
  • You want to support a paid indie app that funds ongoing development.

When FreeDictate is the better fit

  • You want it free, with no license key.
  • You want zero configuration beyond picking a button.
  • You want to talk with a mouse button or a lone modifier key.
  • You already use Hammerspoon, or don't mind it running in the menu bar.

Try FreeDictate in a few minutes

You need a Mac and Homebrew. One command installs whisper-cpp, ffmpeg and Hammerspoon, downloads the speech model once, and opens a Setup window that walks you through microphone access, Accessibility access and choosing your button, then lets you try it live.

git clone https://github.com/owenmonagan/freedictate.git
cd freedictate
./install.sh

If it isn't for you, ./uninstall.sh removes it. See the install guide for details.
