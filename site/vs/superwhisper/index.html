FreeDictate vs Superwhisper: a free Superwhisper alternative

Superwhisper is a capable paid app with modes, models and AI options. FreeDictate is the free, one-button version of the core job: talk, and your words appear.

The short answer

Superwhisper and FreeDictate both build on OpenAI's Whisper family of speech models and both can transcribe locally on a Mac. Superwhisper adds a lot on top: multiple modes, a choice of models, and optional AI processing. It's a paid product. FreeDictate deliberately adds almost nothing on top. It's free, open source, and has one setting: your button.

If you've been looking for a Superwhisper alternative that's free and doesn't ask you to choose between modes, that's what FreeDictate is for.

Simplicity is the feature

Superwhisper's strength is flexibility. You can set up different modes for emails, notes or messages, swap models, and route text through a language model. Power users love that. It also means decisions: which model, which mode, which settings.

FreeDictate makes those decisions once, for everyone. It uses large-v3-turbo, a fast, accurate Whisper model quantized to about 550 MB, served by a local whisper-server that stays warm so there's no model load on each press. There are no modes. What you say is what gets pasted.

Price

Superwhisper sells paid access to its full feature set. FreeDictate is free under the MIT license, with no account and no upgrade screen. You can fork it, change it or ship it inside your own setup.

How FreeDictate works

FreeDictate is a small open-source app built on Hammerspoon, ffmpeg and whisper.cpp. You pick one talk button: any key, a combo, a lone modifier like Right Option, or the middle, back or forward mouse button. Hold it and talk, then let go. Or tap it to start and tap again to stop. A press shorter than 0.35 seconds counts as a tap. Esc cancels.

While you talk, ffmpeg records 16 kHz mono audio to a temporary file and a small pill at the bottom of the screen shows a live level meter. When you stop, the audio goes to a local whisper-server on 127.0.0.1:8178, which only your Mac can reach. It runs the large-v3-turbo Whisper model, quantized to about 550 MB. If the server is down, FreeDictate falls back to whisper-cli. The text is pasted into whatever app has focus with ⌘V, and your clipboard is put back afterwards.

There is no account, no subscription and no pro tier. It's MIT-licensed, so you can read every line.

The button

Most dictation apps use a keyboard shortcut. FreeDictate lets you use one too, but it also lets you use a lone modifier like Right Option, or a mouse button: middle, back or forward. If you have a mouse with spare side buttons, holding the back button to talk is hard to give up. Hold for push-to-talk, or tap to start and tap again to stop.

When to choose Superwhisper instead

  • You want modes. Different behaviour for emails, notes and messages is something Superwhisper is built around. FreeDictate has none.
  • You want AI post-processing. Superwhisper can clean up or reformat what you said with a language model. FreeDictate pastes Whisper's transcript as-is.
  • You want to pick models. If you want a smaller model for speed or a different one for a language, Superwhisper gives you that control.
  • You want a native app with support. Superwhisper is a polished commercial app. FreeDictate runs on Hammerspoon and is supported through GitHub issues.
  • You use an iPhone or iPad too. FreeDictate is Mac only.

When FreeDictate is the better fit

  • You want the core job done, for $0, without picking options.
  • You want everything on-device, with no cloud features to switch off.
  • You want a mouse button as your talk key.
  • You want open-source code you can audit.

Try FreeDictate in a few minutes

You need a Mac and Homebrew. One command installs whisper-cpp, ffmpeg and Hammerspoon, downloads the speech model once, and opens a Setup window that walks you through microphone access, Accessibility access and choosing your button, then lets you try it live.

git clone https://github.com/owenmonagan/freedictate.git
cd freedictate
./install.sh

If it isn't for you, ./uninstall.sh removes it. See the install guide for details.
